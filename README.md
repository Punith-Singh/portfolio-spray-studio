# Portfolio Spray Studio

An interactive portfolio for Punith H Singh, featuring selected Android, web, and computer vision projects. Open a project slip to view its details. Click the launcher or **Spray my work**, or press **Space**, to spray a slip. Hold **Space** to keep spraying until you release it. **Clean up** clears the stage and resets the counter.

This is a static site with no build step. Open `dist/index.html` in a browser or serve the `dist` directory with a static server. Profile information and project links are in `dist/index.html`, styles in `dist/style.css`, and launcher behavior in `dist/script.js`.
