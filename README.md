# Portfolio Spray Studio

A playful, responsive portfolio inspired by the supplied screen recording. Click the launcher, press **Spray my work**, or press the space bar to send colorful labels flying. **Clean up** clears the labels.

This is a static website with no installation or build step. Open `dist/index.html` in a browser, or serve the `dist` directory with any static server. Edit the copy in `dist/index.html`, the styles in `dist/style.css`, and the example labels in `dist/script.js`. The name, project labels, and email address are placeholders; replace them before sharing.
